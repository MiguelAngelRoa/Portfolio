# Portfolio - Miguel Roa

Sitio web personal para mostrar mis proyectos y trabajos como desarrollador.

## Tech Stack

- **React** + **TypeScript**
- **Vite** (bundler)
- **Framer Motion** (animaciones)
- **React Icons** (iconografia)
- **Formspree** (envio de correos)

## Ejecutar localmente

```bash
git clone https://github.com/MiguelAngelRoa/Portfolio.git
cd Portfolio
npm install
npm run dev
```

Abre `http://localhost:5173` en tu navegador.

## Deploy

```bash
npm run build
npm run deploy
```

## Estructura

```
src/

```
